# Taitung.md 設計系統

> 空氣感為主體，山海色做強調，織紋用在文化區塊。
> 像台東的空氣——安靜、乾淨、讓人想深呼吸。

---

## 一、設計原則

1. **呼吸感**：大量留白，讓內容有空間，不擁擠。讀文章時應該感覺像在台東散步，不是在趕路。
2. **地方的溫度**：不冷冰冰的科技感，色彩和字型帶有土地的暖度。
3. **文化在細節裡**：原住民織紋和圖騰不是裝飾品，而是有意義地出現在對應的文化區塊。
4. **感官優先**：首頁的海洋英雄區是視覺焦點，讓人先感受到海、空氣、陽光，再開始讀內容。
5. **不同聲道，不同質感**：學術、口述、田野、青年四種聲道各有微妙的視覺區分。

## 三、字型系統

### 字型選擇

| 用途 | 字型 | 備選 | 理由 |
|------|------|------|------|
| **中文標題** | Noto Serif TC | 思源宋體 | 襯線體帶有文化質感和份量，適合地方知識庫的定位 |
| **中文內文** | Noto Sans TC | 思源黑體 | 無襯線，螢幕閱讀舒適 |
| **英文裝飾/標題** | Cormorant Garamond (300/400/600/700/italic) | — | 古典優雅的襯線體，帶人文質感，與 Noto Serif 風格相襯 |
| **英文內文** | Noto Sans TC 內嵌的拉丁字集 | Inter（備選） | 與中文內文一致 |
| **程式碼 / 數據** | JetBrains Mono | — | 等寬字型，資料呈現清楚 |

### 字級系統

以 `rem` 為單位，基準 `1rem = 16px`。

| 名稱 | 大小 | 行高 | 用途 |
|------|------|------|------|
| display | 2.5rem (40px) | 1.2 | 首頁大標題、地圖上的地名 |
| h1 | 2rem (32px) | 1.3 | 文章標題 |
| h2 | 1.5rem (24px) | 1.35 | 段落標題 |
| h3 | 1.25rem (20px) | 1.4 | 小節標題 |
| body | 1.125rem (18px) | 1.75 | 文章內文（比一般網站大一點，閱讀舒適） |
| small | 0.875rem (14px) | 1.5 | 標籤、caption、meta 資訊 |
| tiny | 0.75rem (12px) | 1.4 | 地圖上的小標記 |

### 文章內文排版

- 最大寬度：`680px`（長文閱讀的舒適寬度）
- 段落間距：`1.5em`
- 首段不縮排，段與段之間用空行區隔

## 七、動畫與互動

- **頁面切換**：淡入淡出（200ms ease-out），不用滑動
- **卡片 hover**：微上移 2px + 邊框色變化（150ms）
- **地圖互動**：平滑的縮放和平移（Mapbox 預設），知識節點 hover 時放大 1.2x
- **聲道切換**：底線指示器平滑滑動（250ms）
- **地景層切換**：地圖標記淡入/淡出（300ms）
- **季節橫幅**：首次載入時從上方輕柔滑入
- 原則：**動畫是用來引導注意力的，不是用來表演的。**所有動畫都要能被 `prefers-reduced-motion` 關閉。

## 九、織紋使用規範

原住民織紋和圖騰**不是裝飾品**。使用規範：

1. **只用在對應文化的區塊**：阿美族的紋樣只出現在阿美族相關內容中
2. **不混用族群圖騰**：每個族群的紋樣是獨特的，不能混搭
3. **取得授權**：使用任何具體的族群圖騰前，需確認是否有文化敏感性或授權需求
4. **幾何暗紋為安全選項**：在通用的文化區塊，使用不指向特定族群的幾何暗紋（低對比度背景紋理）
5. **永遠不要把織紋用在商業推廣素材上**

---

## 十、無障礙

- 所有文字對比度達 WCAG AA（4.5:1 以上）
- 互動元素有清楚的 focus 樣式（太平洋藍外框）
- 圖片必須有 alt text
- 音檔必須有逐字稿
- 地圖有純文字替代導航（for 螢幕閱讀器）
- 支援 `prefers-reduced-motion` 和 `prefers-color-scheme`
