> 目標：打造台東版的 Taiwan.md，以國立臺東大學為核心起點，建立 AI 友善的台東開源知識庫。

## 一、Taiwan.md 專案深度解析

### 1.1 技術棧

| 項目 | 選擇 |
|------|------|
| 前端框架 | Next.js（React 框架）+ MDX |
| 內容格式 | Markdown + YAML Frontmatter |
| 資料視覺化 | D3.js（知識圖譜 force simulation + 資源心智圖 bidirectional tidy tree） |
| 品質控制 | `detect-ai-hollow.sh` 14 維度自動檢測腳本 |
| 託管 | GitHub Pages |
| CLI 工具 | NPM 套件（`npx taiwanmd`）支援閱讀、測驗、搜尋、RAG |

### 1.2 內容架構

- **940+ 篇文章**，13 個主分類，~100 個次分類（MECE 原則）
- **多語系**：繁中 413 篇、英文 479 篇、西班牙文 34 篇、日文 12 篇
- **三層閱讀深度**：30 秒概覽 → 5 分鐘閱讀 → 完整文章
- **多觀點系統**：YAML frontmatter 中的 `perspectives:` 欄位標記觀點（主流學術觀點、台灣主體性觀點、中華民國法律觀點等）
- 目錄結構：文章存放於 `knowledge/` 目錄，按分類組織

### 1.3 AI 原生設計

- `/llms.txt`：供 ChatGPT、Claude、Gemini 理解專案上下文
- `robots.txt`：完全開放 AI 爬蟲索引
- 機器可讀的 frontmatter 元數據
- 結構化 Markdown 讓 LLM 可直接消費內容

### 1.4 14 維度品質控制系統（`detect-ai-hollow.sh`）

自動檢測以下維度，目標分數 ≤3：
1. 符號填充（bullet padding）
2. 缺少日期
3. 無來源引用
4. 空修飾語
5. 重複結構
6. 薄弱段落
7. 無人工審核跡象
8. 塑膠般的措辭
9. 破折號濫用
10. 教科書式開頭
11. 陳詞濫調結尾
12. 樣板化的 H2 標題
13. 列表傾倒檢測
14. 品質衰退

### 1.5 編輯哲學

- **策劃非生成**：AI 是策展人而非作者，優先蒐集高品質來源再策展
- **精選非完整**：不追求百科全書式完整，追求每篇都能讓人「喔，我懂了！」
- **建築即政策**：架構本身反映編輯政策
- **報導者風格**：參考《報導者》深度報導，每 2-3 段穿插策展者評論
- **事實可驗證**：所有數據附來源引用
- 三階段品質管線：研究 → 撰寫 → 驗證

### 1.6 貢獻模式

1. 直接寫作 → 團隊協助格式化
2. AI 輔助貢獻 → 貼 prompt 到 AI，引導產出 Markdown
3. 翻譯貢獻 → TRANSLATION-BOARD.md 追蹤進度
4. 非技術貢獻者也能參與

## 二、臺東大學（NTTU）深度資料

### 2.1 學院與系所

#### 人文學院
- **華語文學系**暨碩士班：華語及文學研究
- **英美語文學系**：英語語言與文學
- **音樂學系**：管弦樂團、合唱團、管樂團，每年舉辦重要音樂展演
- **南島文化研究博士班**：台灣唯一南島文化專業博士班，全英文授課
- **南島文化研究碩士班**

#### 師範學院
- **教育學系**：學士、碩士、博士完整學程（教育行政、輔導、教學科技）
- **幼兒教育學系**：幼兒發展、課程教學、文學、藝術、運動
- **特殊教育學系**：多元教育需求

#### 理工學院
- **資訊管理學系**：含碩士班、博士班
- **生命科學系**：生物技術與生態資源應用
- **身心整合與運動休閒產業學系**

#### 其他教學單位
- 體育學系
- 文化資源與休閒產業學系：整合綠色休閒產業與人文歷史
- 食品生物技術應用二年制在職學位學程

## 三、台東文化與產業深度資料

### 3.1 原住民族群分布

台東人口約 22 萬，其中三分之一為原住民，共有 6 個主要族群：

| 族群 | 分布地區 | 文化特色 |
|------|----------|----------|
| **阿美族** | 關山、長濱、成功、東河、池上、鹿野、太麻里 | 分南勢、中、南三群，台東最大原住民族群 |
| **排灣族** | 金峰、達仁、太麻里、大武 | 嚴格貴族與平民階級，服飾與雕刻工藝卓越 |
| **布農族** | 海端、延平 | 典型高山住民，傳統狩獵與農業文化 |
| **卑南族** | 台東市周邊 | 卑南遺址所在，豐富祭典文化 |
| **魯凱族** | 部分山區 | 石板屋文化、百合花象徵 |
| **達悟族（雅美族）** | 蘭嶼 | 拼板舟文化、飛魚祭、地下屋 |

### 3.2 史前文化與考古

- **卑南遺址**：1988 年列為國家一級古蹟，環太平洋最大墓葬群之一，文化堆積最厚達 3 公尺以上
- **卑南文化公園**：1991 年規劃
- **國立台灣史前文化博物館**：2002 年開幕，全台東部唯一國家級博物館，含康樂本館、卑南遺址公園、南科考古館
- **數位典藏**：考古資料數位典藏創新計畫提供 3D 文物、GIS 系統

### 3.3 地方創生案例

| 案例 | 說明 |
|------|------|
| **鹿野鄉** | 紅烏龍茶品牌化，產業六級化發展，年產值上億 |
| **池上鄉** | 國際慢城認證，優質米產業，農村體驗 |
| **都蘭** | 東部海岸最大部落，阿美族文化創生 |
| **南迴地區** | 歷坵、嘉蘭、正興村，洛神花、小米產業 |
| **大武鄉** | 台灣第一個公部門數位遊牧基地（2022 年啟用） |

### 3.4 特色產業

| 產業 | 說明 |
|------|------|
| **釋迦** | 佔全台種植面積 85%（約 5,400 公頃），全球第一大出口國 |
| **紅烏龍茶** | 2008 年於鹿野推出，重發酵特殊製程，橙紅茶湯 |
| **池上米 / 關山米** | 肥沃土壤與充沛雨量造就優質品牌米 |
| **洛神花** | 主要產區歷坵社區（魯拉克斯部落） |
| **小米酒** | 原住民傳統釀造文化，月桃葉密封 |
| **月桃** | 釀酒密封、食品包裝、工藝品 |

### 3.5 自然生態

| 地點 | 特色 |
|------|------|
| **綠島** | 火山島嶼，海底溫泉，世界最巨大活珊瑚「大香菇頭」 |
| **蘭嶼** | 達悟族家園，角鴞（僅存約 600 隻）、椰子蟹 |
| **嘉明湖** | 「天使的眼淚」高山湖泊 |
| **三仙台** | 八拱跨海步橋，珊瑚礁海岸 |
| **太麻里** | 日出之鄉，金針花海 |

### 3.6 藝文空間

- **臺東藝文中心**：1,216 席演藝廳、232 席演講廳
- **臺東美術館**：「山歌」及「海舞」兩展廳 + 文創教室、駐村藝術家空間
- **台東糖廠文創園區**：原東南亞最大鳳梨工廠，34 家進駐廠商

### 3.7 重要活動

- **臺灣國際熱氣球嘉年華**：2011 年首辦，2022 年創 123 萬人次紀錄，獲美國繆思創意大獎鉑金獎，世界最長熱氣球節（76 天）
- **南島文化節**
- **池上秋收稻穗藝術節**

## 七、Taitung.md 策略建議

### 7.1 定位

> 以臺東大學為核心，讓全世界認識台東——開源、AI 友善、社群驅動的台東知識庫。

1. **原住民語言內容**：加入阿美語、卑南語、達悟語等版本（全球獨特性）

### 7.5 分階段推進

**Phase 3：生態整合（6-12 個月）**
