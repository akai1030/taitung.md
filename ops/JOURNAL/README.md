# JOURNAL — 研究日誌

> 沒有日誌，跑一百次就是重複第一次。這是整個迴圈能不能累積的唯一關鍵。
> 強制規則：`HARD-RULES.md` H19

檔名：`YYYY-MM-DD.md`（同日多輪加 `-2`、`-3`）

---

## 格式

```markdown
# YYYY-MM-DD 第 N 輪

## 0. 框架挑戰（GOVERNANCE §0.5）
Q1 先例：
Q2 自創 vs 既有：
Q3 我的傾向哪來的：
Q4 誰會反對：
Q5 會怎麼失敗：
Q6 我沒問的問題：
Q7 該先查完再動工的：
→ 針對上述實際做了哪些檢索？（沒查就不能動工）

## 1. 這輪想回答什麼
對應 CHARTER A/B/C 哪一軸？

## 2. 檢索紀錄（PRISMA-S）
| 平台 | 檢索式 | 日期 | 語言 | 結果筆數 | 去重後 | 納入 |
|---|---|---|---|---|---|---|
（筆數 0 也要記——那是缺口分析的原始資料）

## 3. 發現
依 METHOD §3 標確信度：verified / attested / inferred / gap / disputed

## 4. 推翻了什麼
**最重要的一節。** 這輪推翻了先前哪個假設？
若連續三輪都沒有推翻任何東西 → 這個迴圈在確認偏誤裡打轉，月度回顧要處理。

## 5. 失敗與卡關

## 6. 下一步
寫進 BACKLOG 的具體項目
```

---

## 為什麼第 4 節最重要

一個從不推翻自己的研究迴圈，只是在用越來越多的證據確認一開始就相信的東西。
`CHARTER.md` 的論點是**可被推翻的**——如果跑了半年，論點從沒被任何證據挑戰過，
那不代表論點很強，代表檢索方式在系統性地避開反證。
