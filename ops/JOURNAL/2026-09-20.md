## 3. 發現

### F157（`attested`，B 軸）—— 排灣族最後一個絕對零覆蓋族群可及，且金峰鄉（十六鄉鎮唯一零覆蓋）同時解除

本輪查證後寫成 `content/jialan-morakot.md`（新開 PR，T3），主題是金峰鄉嘉蘭村在 2009 年莫拉克風災中的經歷與災後自我組織（「88 嘉蘭山寨」）。並列五段獨立來源：台灣光華雜誌 2009 年報導、維基百科〈金峰鄉〉條目、教育部《臺灣原住民族事典》Maledep部落條目、原住民族委員會排灣族介紹頁、ETtoday 2021 年報導。`npx tsx scripts/audit-content.ts --links` 對此篇零 FAIL，6 筆 WARN（H1×3〔其中 2 筆是「第一人稱」被規則誤判為「一人」的既知假陽性，1 筆是「2010 年代」缺行內歸屬〕、H13×1〔「巫師」命中受限詞表，但只是轉述 CIP 對排灣族五階級社會組織的一般性描述，非祭儀細節〕、H7×2〔「大武」「太麻里」各一次未加限定詞〕）。

這是本站同時解除兩個矩陣座標的第二個案例（第一個是 09-19 卑南鄉／魯凱族）——金峰鄉此前是台東縣十六鄉鎮市裡**唯一**完全零主體內容的鄉，排灣族此前是台東七族裡**唯一**仍是絕對零主體內容的族群，且兩者本身就重疊（金峰鄉是台東縣排灣族分布最集中的鄉之一）。至此，`ops/COVERAGE.md` 記錄的十六鄉鎮市與七族群矩陣，理論上不再有任何一格是完全零覆蓋——但這個「填滿」本身需要下一節的但書。

### F158（`attested`／誠實缺口，B 軸，本輪最重要的發現）—— 找到具名族人第一人稱引言，但無法確認其族群身分，缺口沒有真的解決

台灣光華雜誌報導裡有四位具名嘉蘭村民的直接引言——頭目吳榮金之妻戴秀英、退休教導主任宋仙璋、村民賴淑芳、頭目吳榮金本人——這是本站在排灣族相關主題上第一次找到具名、第一人稱、且核對過報導全文的當代材料，材料品質本身優於此前布農族／魯凱族兩輪（皆只有機構或單一段落引言）。

但本輪查證後必須誠實記錄一個查證過程中才浮現的具體限制：嘉蘭村是「7 個排灣族部落及 1 個魯凱族部落」組成的混居聚落，報導本身**未逐一標註**每位受訪者屬於哪個族群。這代表本站雖然找到了具名族人的話，卻**無法把這些引言精確地歸給「排灣族」或「魯凱族」其中一族**——如果本站在缺口矩陣裡把這篇文章記成「排灣族當代生活缺口已解決」，那是一個沒有被本輪材料真正支撐的斷言。這比「零覆蓋」更精細：**格子被填上了，但填格子所依據的材料本身帶著一個沒有被解決的歸屬問題**，這是本輪查證前沒有預期到的發現，不是動工前就知道要記錄的但書。

## 5. 失敗與卡關

- 台灣光華雜誌文章 URL 用 `WebFetch` 工具讀取時回報「Too many redirects」，改用 `curl`（帶瀏覽器 User-Agent）直接讀取成功（HTTP 200，無任何重導向）。稽核腳本 `--links` 模式下，同一 URL 被 Node.js 原生 `fetch()` 判定為「無回應」，本輪進一步排查發現：`curl`（透過本機環境設定的 proxy）與 Node `fetch()`（未使用該 proxy，也未讀取 `https_proxy` 環境變數）對同一 URL 行為不同，Node 端報錯是「redirect count exceeded」而非逾時或 4xx/5xx，判定為**本輪執行環境的網路代理設定問題**，不是連結本身死亡——已用 curl 與瀏覽器等效的請求交叉確認網站本身完全正常。這與既有 B-028（HEAD 遭反爬蟲擋下）是同一類「H4 誤判」但成因不同（這次是代理設定，非站台本身的反爬蟲策略），已記入 `ops/BACKLOG.md` B-028 附記，供下一輪或有能力檢查稽核腳本執行環境（含 GitHub Actions CI 本身是否也有同樣代理限制）的 session 參考——**CI 環境很可能沒有這個代理限制**（代理是本輪所在的沙盒環境特有設定），本輪未查證 GitHub Actions 是否也會誤判此連結，留給下一輪或直接觀察 CI 執行結果。
