## 為什麼參考文件這麼多，強制規則卻只有一頁

維基百科花了三年治理 AI 內容，結論是**「全面性失敗，極簡主義成功」**。

所以這裡切成兩層：
- **`HARD-RULES.md`** — 21 條，每一條都對應 `scripts/audit-content.ts` 裡真的跑得起來的檢查
- **其餘七份** — 推理紀錄。說明每條規則**為什麼**存在、查過哪些文獻、哪裡改過主意

**不能被執行的規則不是規則，是願望。** 但把推理丟掉，下一輪的 agent 就會重新犯同樣的錯——所以推理要留，只是不給它強制力。

## 三個誠實的限制

1. **`ops/METRICS.md` 的「部落實際參與數 = 0」**。在它大於 0 之前，整套倫理設計都是善意的代理決策——比沒有好，但不是同意。
2. **開源與資料主權在結構上衝突**（`BACKLOG.md` B-005），尚未解決。
3. **所有審議角色由同一個底層模型扮演**，觀點沒有真正獨立（`GOVERNANCE.md` §6.5）。無解，只能靠人類抽查。
