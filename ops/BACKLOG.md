### B-001 — 灰色文獻入口的可及性方案　【2026-08-11 重大轉折：搜尋介面不可及≠資料不可及，見 JOURNAL 2026-08-11】
**軸**：A｜**來源**：JOURNAL 2026-08-06 §2.2

GRB（Angular SPA，無公開 API）與 NDLTD（需 session）皆無法簡單 HTTP 存取。這推翻了 `METHOD.md` §4.2 的假設。而灰色文獻是本專案宣稱的核心優勢——**這個優勢目前是不可及的。**

選項：(a) headless browser（成本高、脆弱）(b) 改用 WebFetch 逐頁（慢但可行）(c) 找替代入口（華藝、Google Scholar）(d) 承認並改寫 METHOD

**2026-08-09 逐選項實測結果**：
- **NDLTD**：實測非「需 session」而是**圖形驗證碼硬關卡**（送出查詢前即被攔截）。比原記錄更嚴格。選項 (a)/(b) 對 NDLTD 判定**不可行**——繞過驗證碼屬規避存取管制，超出授權範圍，不做。
- **GRB**：SOURCES.yaml 正式網址 `grbsearch.stpi.narl.org.tw` 今天回傳 **HTTP 503**。單次 503 無法判斷是暫時性維護還是結構性問題，需連續多輪重測才能下結論（已列入下方待查）。
- **Google Scholar**（選項 c 的一部分）：查詢請求被導向 `google.com/sorry`（機器人偵測頁）。**未追蹤該導向**——此舉已等同嘗試繞過反爬蟲機制，判定不做，選項 (c) 對 Google Scholar 判定不可行。
- **Airiti 華藝**（選項 c 的一部分）：搜尋介面需 JS＋機構登入，**但文章「詳情頁」的書目 metadata（不含全文）不需登入即可直接 WebFetch**。已用此法核實 2026-08-08 F7 遺留的兩篇加禮宛事件論文完整書目（見 JOURNAL 2026-08-09 §3 F12）。**這不能取代系統性檢索**，只能用於「已知候選文獻的書目核實」，是選項 (b) 的一個可行變體，範圍有限。

**收斂結論（2026-08-09，已被 2026-08-11 部分推翻，見下）**：選項 (a)(b) 對 NDLTD 不可行；(c) 對 Google Scholar 不可行、對 Airiti 部分可行（僅書目核實，非系統性檢索）；GRB 待重測。

**2026-08-10 重測（連續第 2 輪）**：`grbsearch.stpi.narl.org.tw` 仍為 HTTP 503。同日 CIP、THCTS 查詢平台、中研院 tileserver 同樣 503（見 B-007 進度、JOURNAL 2026-08-10 §0.2），未追查是否有共同成因。

**2026-08-11 重測（連續第 3 輪）確認 503，依 CHARTER §6 正式降級 `grbsearch.stpi.narl.org.tw`（搜尋介面）為 `status: degraded`。但同一輪意外發現：GRB／NDLTD 各自都有官方「批次資料匯出」（data.gov.tw dataset 18707／14024），完全不經過壞掉的搜尋介面或驗證碼，實測可下載、可解析、能命中台東相關筆數（GRB 115年度7筆、100年度65筆；NDLTD 113學年度16筆，見 SOURCES.yaml `alt_access` 與 JOURNAL 2026-08-11 F19-F21）。**「(d) 承認並改寫 METHOD」的必要性沒有上升，反而部分被繞過**——METHOD.md §4.2 已於本輪更新，記錄「搜尋介面故障 ≠ 資料不可及，應先查官方批次匯出」這個方法論教訓。**結案，轉為 B-022（見下）延續。**

**2026-08-27 第三次驗證（見 JOURNAL 2026-08-27 F79）**：`nchdb.boch.gov.tw`（國家文化資產網）個案詳細頁同樣是前端 SPA（Next.js）空殼，WebFetch／curl 皆讀不到實際資料，與 GRB（Angular SPA）同構。但文化資產局在 `data.boch.gov.tw` 提供官方批次開放資料 JSON（data.gov.tw dataset 6965，OGDL-1.0，1788筆全國歷史建築案卷），下載後可直接解析取得目標案卷完整欄位。同一教訓在第三個網域（GRB → NDLTD → 文化資產局）成立：遇到政府 SPA 查詢介面打不開，第一直覺應是找官方批次開放資料，不是放棄或改用 headless browser。

### B-023 — `license` 欄位語意：引用受著作權保護但非開放授權的來源　【2026-08-13 擴大範圍，見 JOURNAL 2026-08-13 F31】
**軸**：跨軸（規則體系）｜**來源**：JOURNAL 2026-08-12，`green-island.md` 補完過程；JOURNAL 2026-08-13，`surfing.md` 補完過程

`HARD-RULES.md` H14 的措辭與範例（`ogdl-1.0 / cc-by-4.0 / public-domain / unknown`）預設來源是「可重製的開放資料」。但兩種常見情況不完全符合這個預設：
1. 引用一般新聞報導的事實（附連結、註明出處、不重製全文）——新聞機構通常不提供開放再散布授權
2. **（2026-08-13 新增）政府觀光網站雖有「政府網站資料開放宣告」連結，但實際條款是「合理範圍內得重製、公開傳輸並註明出處」的限定範圍著作權模式，不是 OGDL**（實測案例：`eastcoast-nsa.gov.tw/zh-tw/siteinformation/gwoia/`）

本輪暫定處理（兩案例一致）：`license: all-rights-reserved`（明確的已知著作權狀態，不是 `unknown`）可通過 H14 稽核。這個解讀**未經人類確認**，累積案例：自由時報／公視新聞網（2026-08-12）、東部海岸國家風景區管理處（2026-08-13）。待裁決：
- 若成立 → 把 `all-rights-reserved` 正式納入可接受的 license 詞彙表，並在 `HARD-RULES.md`／`METHOD.md` 寫清楚「引用」與「重製」的區別，且明確涵蓋「有開放宣告連結但條款非開放授權」這種政府網站常見模式
- 若不成立 → 需追溯檢討 `green-island.md`（自由時報、公視新聞網）與 `surfing.md`（東部海岸國家風景區管理處三頁、台東觀光旅遊網一頁）引用的來源是否該用別的方式標註或整篇不採用
